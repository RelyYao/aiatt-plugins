# 行为准则 / Code of conduct

## 中文

我们希望这里是一个让写游戏的人安心合作的地方。

- **尊重他人**：对事不对人，批评代码和设计，不攻击人；不使用歧视、骚扰、威胁或羞辱性的语言。
- **欢迎新人**：耐心解答，给出能照着改的意见。
- **诚实**：不冒用他人作品，不提交自己无权授权的代码或素材，不隐瞒已知的安全问题。
- **保护隐私**：不公开他人的个人信息，不在 issue 和合并请求里贴密钥、令牌或内部地址。
- **内容适当**：插件和素材不得含有色情、暴力煽动、歧视、违法或误导性的内容。

维护者可以删除不符合准则的评论、关闭合并请求、限制或移除违反准则的参与者。遇到问题可以开 issue 并 @ 维护者；不便公开的（例如涉及个人信息或骚扰），请用 Security 标签页的「Report a vulnerability」私下提交，标题写「行为准则」，只有维护者能看到；涉及安全的问题请按 [SECURITY.md](SECURITY.md) 处理。

## English

We want this to be a place where game authors can work together with peace of mind.

- **Respect people**: criticize code and design, not people; no discriminatory, harassing, threatening or demeaning language.
- **Welcome newcomers**: answer patiently and give feedback they can act on.
- **Be honest**: do not pass off others' work as yours, do not submit code or assets you have no right to license, do not hide a known security problem.
- **Protect privacy**: do not publish others' personal information; never paste keys, tokens or internal addresses into issues or pull requests.
- **Keep content appropriate**: plugins and assets must not contain sexual content, incitement to violence, discrimination, illegal or misleading material.

Maintainers may remove comments, close pull requests, and restrict or remove participants who break these rules. Raise concerns in an issue and mention the maintainers; for anything that should stay private (personal information, harassment), use "Report a vulnerability" on the Security tab with a title starting "Code of conduct", which only the maintainers can see; for security matters follow [SECURITY.md](SECURITY.md).
